---
title: Hotkeys
description: The default chords for dictation and Command Mode, and how to change them.
---

Kass uses chords: keys you hold together. The defaults use the modifier keys on the **right** side of the keyboard, so they don't collide with the shortcuts you already use. Left and right modifiers count as different keys.

| Action | Default chord |
| --- | --- |
| Dictate (hold to talk) | <kbd>right ⌘</kbd> + <kbd>right ⌥</kbd> |
| Dictate hands-free | <kbd>right ⌘</kbd> + <kbd>right ⌥</kbd> + <kbd>Space</kbd> |
| Command Mode | <kbd>right ⌘</kbd> + <kbd>right ⇧</kbd> |
| Cancel | <kbd>Esc</kbd> |

## Hold to talk

Hold the chord while you speak and let go when you're done. This is the fastest way to dictate a sentence or two.

## Hands-free

Tap <kbd>Space</kbd> while you're holding the dictation chord. The take switches to hands-free without losing any audio, so you can let go and keep talking. Press the hands-free chord to finish.

You can also start hands-free directly: press <kbd>right ⌘</kbd> + <kbd>right ⌥</kbd> + <kbd>Space</kbd> once to start and once more to stop.

## Cancel

<kbd>Esc</kbd> cancels a take from the moment you press the chord until its text starts going into your app, including while it's still being transcribed or cleaned up. The <kbd>Esc</kbd> press still reaches the app you're in.

## Change a chord

1. Open **Settings › Dictation** and click **Change** next to the chord.
2. Hold the keys you want, then let go.
3. Click **Save**.

A chord can have one to six keys. Keys that can't be used show a message saying they aren't supported in chords. The Command Mode chord is set in **Settings › Command Mode**, and it must be different from the dictation chords.

:::note
Chords need **Input Monitoring** permission. If nothing happens when you hold a chord, check that Kass is allowed in **System Settings › Privacy & Security › Input Monitoring** and that the global shortcut is on in **Settings › Dictation**.
:::
