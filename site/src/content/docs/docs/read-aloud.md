---
title: Read Aloud
description: Select text in any app and hear it in a natural voice.
---

Dictation turns your voice into text. Read Aloud does the reverse: select text in any app, press the Read Aloud keys, and Kass reads it to you. The voice runs on your Mac, like everything else.

## Use it

1. Select text in any app.
2. Press <kbd>right ⌥</kbd> + <kbd>right ⇧</kbd>.
3. Kass reads the selection aloud, and the pill shows **Speaking**.

To stop, press the keys again, press <kbd>Esc</kbd>, or click the pill. Starting a dictation stops it too.

## Set it up

The first time, download the voice model, Kokoro (about 345 MB), from **Settings › Read Aloud** or the **Models** tab. After that, Kass loads it in the background when it opens, so reading starts right away.

In **Settings › Read Aloud** you can also:

- Change the keys, or turn Read Aloud off. The keys must be different from your dictation and Command Mode keys.
- Pick a voice: 28 American and British English voices. **Preview** plays the voice you picked.
- Change the speed, from half to twice normal.

## Limits

- A selection can be up to 16,000 characters, which is several minutes of speech. Kass reads it a sentence at a time.
- Voices are English. Text in other languages is read with English pronunciation.
- Code, URLs and symbols are read as written.
- Password fields are never read. Terminals and web pages can be.
- If nothing is selected, Kass asks you to select text first.
